# گیت خوانایی فارسی همنشین — v1

گیت لوکال و آفلاین برای کامپوزیشن‌های HyperFrames فارسی، ساخته‌شده در پاسخ به ارزیابی
`mad-helpers/motion-harness`: قانون خواناییِ عددی و ایدهٔ «دایجست سبک به‌جای بازبینی
فریمی با VLM» از آن ریپو گرفته شد، ولی موتور گیت از نو نوشته شد — چون گیت آن ریپو
با رگکس فقط `tl.fromTo/tl.to` با اعداد لفظی را می‌دید و روی الگوی واقعی ما
(`tl.add`، تایم‌لاین تو‌در‌تو، لیبل) عملاً همه‌چیز را الکی پاس می‌کرد.

## روش

گیت، تایم‌لاین واقعی (`window.__timelines`) را در Chrome Headless Shell خود
HyperFrames اجرا می‌کند و هر ‎۵۰ms با `seek` از آن نمونه می‌گیرد. برای هر عنصر
متن فارسی (برگِ دارای متن فارسی در DOM) در هر نمونه این‌ها ثبت می‌شود:
opacity مؤثر (با احتساب والدها)، مرکز و پهنای رندرشدهٔ متن (Range rect) و سرعت حرکت.

«ساکن» یعنی: opacity ≥ ‎۰٫۹۸، سرعت مرکز ≤ ‎۴۰px/s و نرخ تغییر اسکیل ≤ ‎۰٫۸٪ در هر
نمونه. ملاک «نرخ تغییر» است نه فاصله از مقدار نهایی، تا دریفت آرام دوربینِ امضای
همنشین (scale ‎۱٫۰۰→۱٫۰۳) متن ساکن را رد نکند ولی ورود و اوورشوت رد شوند.

بدون هیچ کلید API، بدون Jev، بدون ارسال داده به بیرون. زمان اجرا: ~۵ ثانیه برای کلیپ ۶ثانیه‌ای.

## قوانین

| کد | قانون | پیش‌فرض |
|----|-------|---------|
| R1 | مکث ساکن هر متن ≥ ‎max(floor, ‎کلمه × secPerWord) | floor=۱٫۰s ، ‎۰٫۵۰s/کلمه |
| R2 | ‎letter-spacing روی متن فارسی ممنوع (پیوستگی حروف) | — |
| R3 | فونت متن فارسی باید وزیرمتن باشد | ‎--font |
| R4 | جهت بلوک متن فارسی باید rtl باشد | — |
| R5 | «می/نمی + فاصله» به‌جای نیم‌فاصله (ZWNJ) خطاست | — |
| R6 | پروفایل همنشین: مرکز متن در یک‌سوم بالایی قاب (فعلاً هشدار) | ‎--no-hamneshin برای خاموشی |
| R7 | (کمکی/استاتیک) ‎ease خطی ‎"none"/"linear" ممنوع، مگر با کامنت ‎gate-allow-linear | — |
| R8 | پهنای رندرشدهٔ متن ≤ ‎۹۶٪ پهنای قاب (حاشیهٔ امن؛ ‎scrollWidth برای متن وسط‌چین RTL قابل‌اعتماد نیست) | — |

شمارش کلمه: جداسازی روی فاصله؛ ترکیب‌های نیم‌فاصله‌دار («گفت‌وگویی») یک کلمه حساب می‌شوند.

## کالیبراسیون — صادقانه

- ‎۰٫۵۰ ثانیه/کلمه **کالیبره‌شدهٔ ۲۰۲۶-۱۱-۰۳** است (تصمیم سعید): روی ۳ کلیپ واقعی
  همنشین (دموی موشن + سناریو-۳ اصلی و عمودی؛ ۳۷ عنصر، ۱۸ چندکلمه‌ای) اندازه‌گیری شد؛
  تنگ‌ترین مکث واقعی ‎۰٫۶۲–۰٫۶۴ و میانه ‎۰٫۹۶ بود و همهٔ نقاط با ‎۰٫۵۰ پاس شدند.
  ضریب قبلی (‎۰٫۴۲) هیوریستیک v1 بود. گزارش کامل: ‎`CALIBRATION-fa.md` و دادهٔ خام در
  ‎`calibration/`. هنوز تست بیننده انجام نشده؛ کالیبراسیون روی خروجی واقعی است، نه بیننده.
- تشخیص «ساکن‌شدن» با ورودهای ‎back.out تلورانس ~۰٫۱۵–۰٫۳s دارد (اوورشوتِ opacity را
  مرورگر clamp می‌کند). برای مرزهای نزدیک به آستانه، حاشیهٔ امن بگذارید.
- کنتراست WCAG را این گیت تکرار نمی‌کند؛ ‎`hyperframes check` آن را پوشش می‌دهد و باید کنارش اجرا شود.

## استفاده

```bash
node gate/fa_readability_gate.mjs clip            # یا مسیر هر index.html
node gate/fa_readability_gate.mjs clip --json out.json --spw 0.50 --floor 1.0 --dt 0.05
bash tests/run_tests.sh                            # سه تست: سالم / خراب / رگرسیون R8
```

خروج: ‎۰ پاس، ‎۱ فیل، ‎۲ خطای زیرساخت.

## ساختار

- ‎`gate/fa_readability_gate.mjs` — خود گیت (Node ‎۲۴، بدون وابستگی؛ از Chrome کش HyperFrames استفاده می‌کند)
- ‎`clip/` — کلیپ تست ۶ثانیه‌ای همنشین (۱۰۸۰×۱۹۲۰، وزیرمتن لوکال، GSAP ‎۳٫۱۵ وندورشده، پالت قفل: کرم/سبزآبی تیره/آجری، دو صندلی + دو فنجان + نخ)
- ‎`tests/clip-broken/` — همان کلیپ با ۴ تخلف عمدی (خروج زود زیرعنوان، بج فلش، letter-spacing، «می شود»)
- ‎`renders/` — خروجی‌ها: ‎(ویدیوی رندر در این انتشار عمومی نیامده است)، کانتکت‌شیت، فریم ۵s و JSON هر دو اجرای گیت

## نتیجهٔ تست‌ها (۲۰۲۶-۱۱-۰۲، این ماشین)

| مورد | انتظار | نتیجه |
|------|--------|-------|
| کلیپ سالم | PASS | ✓ تایتل: مکث ‎۵٫۰s از ‎۱٫۶۸s لازم؛ زیرعنوان: ‎۳٫۷s از ‎۲٫۹۴s |
| کلیپ خراب | FAIL | ✓ دقیقاً ۴ تخلف: ‎R1 زیرعنوان (‎۰٫۹s از ‎۲٫۹۴s)، ‎R1 بج (‎۰٫۲s از ‎۱٫۶۸s)، ‎R2 letter-spacing، ‎R5 نیم‌فاصله — و تایتل سالم همان کلیپ پاس شد (گیت کورکورانه فیل نمی‌کند) |
| رگرسیون R8 (تایتل ۸۸px) | FAIL با R8 | ✓ پهنای متن ‎۱۰۷۵px در برابر سقف ‎۱۰۳۷px |
| ‎hyperframes check روی کلیپ | پاس | ✓ ‎۰ خطا (۱ هشدار ساختاری خنثی)، کنتراست ‎۸/۸ WCAG AA |
| فریم‌چک انسانی | — | ✓ در فریم‌های ‎۱/۲٫۶/۵s: شیپینگ فارسی بی‌نقص، نیم‌فاصله‌ها درست، نخ بین دو صندلی کامل می‌شود، متن در یک‌سوم بالا با حاشیهٔ امن |

نکتهٔ فریم‌چک: نسخهٔ اول تایتل ۸۸px بود و در لبه‌ها لب‌پر دیده می‌شد، درحالی‌که
‎Layout چک HyperFrames صفر خطا می‌داد — همین مشاهده، قانون R8 را به گیت اضافه کرد
(اول با ‎scrollWidth امتحان شد و روی متن وسط‌چین RTL نگرفت؛ نسخهٔ نهایی Range rect است).

## محدودیت‌های v1

- متن داخل ‎`<text>`‎ های SVG و انیمیشن‌های CSS ‎@keyframes خارج از ‎__timelines پوشش کامل ندارند.
- R5 فقط الگوهای پرتکرار «می/نمی + فعل» را می‌گیرد؛ ویراستار نیم‌فاصلهٔ کامل نیست.
- R6 فعلاً هشدار است، نه خطا.
